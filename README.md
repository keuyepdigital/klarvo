# Klarvo Studio — Static Site
Struktur:
- `index.html`
- `style.css`
- `script.js`
- `CNAME` (isi domain custom, contoh: `klarvostudio.biz.id`)

## Deploy ke GitHub Pages
1. Commit & push file di root repo.
2. Settings → Pages → Source: `main` / root.
3. (Opsional) Custom domain: isi `CNAME` dengan domain Anda lalu atur DNS.
